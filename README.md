__Pustakam__ – Online Book Exchange Store

Pustakam is a web-based online book exchange platform designed to help students and readers buy, sell, and exchange used books at affordable prices. Users can upload their books and make them available for other users, helping reduce book wastage and making educational resources more accessible.

__Technologies Used__

- HTML
- CSS
- JavaScript
- Python
- Django
- SQLite / SQL

__Key Features__

- User registration and login
- Upload and manage books
- Buy and sell used books
- Search and browse available books
- Affordable book exchange
- Database management using Django and SQL
